# Ёлки — концепт нового сайта

Концепт сайта ресторана-бара «Ёлки» (Рязань, Почтовая, 63А).

Весь сайт — один файл `index.html`, фото встроены внутрь. Ничего собирать не нужно.

## Как открыть
- Локально: скачать `index.html` и открыть в браузере.
- Онлайн: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через минуту сайт будет по адресу `https://vadimkriuchkov-bit.github.io/elki/`.

## Что внутри
- Статус «открыто сейчас» по московскому времени
- Акции по дням недели с подсветкой сегодняшнего дня
- Обеды по будням 690 / 790 ₽ с переключателем
- Полное меню кухни, бара и кальянов текстом, с поиском
- 10 авторских коктейлей, авторские кальяны, галерея, 3D-тур
- День рождения −15%, программа Ёлки Family, отзывы, статьи, контакты с картой
- Мобильная панель «Звонок / Меню / Забронировать»
